# NumPy Notes

Hands-on Jupyter notebook covering NumPy from the basics to a small applied example.

## What's inside (`Project1.ipynb`)

- Creating arrays: from lists, from scratch, vectors, matrices and tensors
- NumPy arrays vs Python lists
- Array properties and reshaping
- Array operations, sorting, filtering, boolean masks
- Fancy indexing vs `np.where()`
- Adding, removing and deleting data
- Array compatibility (broadcasting)
- A business-style example using advanced operations
- Storing an image as a matrix and converting it to dark mode

## Run it

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
jupyter notebook Project1.ipynb
```
